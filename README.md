# Data Professional Survey Analysis | Power BI

## Project Overview

This project analyzes survey data from data professionals to understand their career background, salaries, job roles, programming preferences, and overall job satisfaction.

The project was developed using Microsoft Power BI with Excel as the source dataset.

## Tools Used

* Power BI
* Microsoft Excel
* Power Query
* DAX

## Dataset

The dataset contains survey responses from data professionals covering areas such as:

* Job role
* Salary
* Programming languages
* Work-life balance
* Job satisfaction
* Difficulty of entering the data field
* Geographic information

## Project Workflow

1. Imported the Excel dataset into Power BI.
2. Cleaned and transformed the data using Power Query.
3. Created calculated columns and measures using DAX.
4. Built interactive visualizations.
5. Created a dashboard to analyze trends and patterns.
6. Added filters and interactive elements for exploration.
